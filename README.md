## 手动获取 cookie 方法
0. 进入 `main` 分支;
1. 用 `VSCode` 打开工程，选中 `cookie.py`;
2. 在 `cookie.py` 的 `#TODO:` 处打个断点;
3. 按 `F5` 运行 `.py` 文件，弹出 `BiliBili` 登录页面;
4. 用手机 `APP` 扫码登录后按 `F5` 使其运行完毕，断点可保留，之后用命令行以非 debug 模式运行。
